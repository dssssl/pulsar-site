# 欢迎来到 Apache Pulsar™ 文档门户
***

此门户收录了丰富的主题、教程、指南与参考资料，帮助你高效使用 Pulsar。

## 选择你的路径
从下方内容块中挑选入口，开启 Pulsar 之旅。如果你……
* 是 Pulsar 新手，请从 **关于 Pulsar** 入门，了解功能与概念。
* 想直接体验，请选择 **快速开始**。
* 负责架构与运维，请前往 **安装、部署、升级**。
* 希望深入开发，请选择 **开发者专区**。
* 想动手实践，请访问 **操作指南** 获取“Hello World”示例。
* 是经验丰富的 Pulsar 开发者，正在查阅 API、指标或配置文档，请前往 **参考资料**。

## 持续改进
***

我们正在为文档门户打造全新的体验，让你更轻松地了解并构建 Apache Pulsar。无论是概念综述、操作步骤、精选指南还是速查文档，我们都会持续补充内容。此欢迎页只是第一步，我们会每月更新进展。

## 帮助我们做得更好
***

欢迎、也需要你的参与！

📚 你可以通过以下方式改进 Pulsar 文档：

- **提交 Pull Request**：每页底部都提供“Edit this page”链接。点击链接并遵循 [Pulsar 文档贡献指南](pathname:///contribute/document-intro)。

- **💡 提出建议**：如果发现错误、内容不完整，或暂时无法提交 PR，可点击页面右上角的相应链接反馈建议。
- **🛟 获取支持**：若在文档中仍有疑问，或想提出一般性问题，可点击页面右上角的支持链接向社区求助，回答也将帮助其他读者。

## 加入社区！
***

Pulsar 社区在 GitHub 上活跃、热情且经验丰富。参与讨论、提出想法、分享特性建议，甚至直接参与代码贡献。欢迎加入 [apache/pulsar](https://github.com/apache/pulsar)。

* 请访问 [社区页面](pathname:///community/#section-discussions) 查找各类沟通渠道。
* Apache Pulsar 项目的主要沟通方式是 [邮件列表](pathname:///contact/)。
* 安全公告与安全策略请参见专门的 [安全页面](pathname:///security/)。
